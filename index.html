隐私政策

生效及更新日期: 2026-09-28 · Jocelyn

本政策适用于 Jocelyn 提供的萌宠家园（Critter Zones，Android 包名 com.critterzones.puzzle）当前离线版本，以及本隐私政策网页。

离线游玩 · 无需账号 · 无广告 · 无充值

1. 游戏处理哪些数据

游戏在设备的应用私有存储中保存关卡进度、棋盘与撤销记录、成绩、金币、提示券、已解锁和选中的动物、每日挑战记录及设置。这些数据用于继续游戏、计算奖励和记住偏好。游戏会读取设备语言以选择初始界面语言，使用设备日期计算每日挑战。

游戏不向我们或第三方服务器上传这些记录，不提供账号、云存档、广告、在线统计或真实货币支付，不收集广告标识符。当前 Android 配置已关闭应用数据的系统自动备份。

2. 权限与本地诊断

游戏使用振动权限提供操作反馈，可在设置中关闭振动。不请求相机、麦克风、通讯录或位置权限，当前发行配置不申请联网权限。

运行时可能在设备本地输出游戏事件及错误诊断日志，游戏不会主动上传这些日志。只有你主动通过邮件分享截图、日志等资料时，我们才会收到相应内容。

3. 主动联系我们

如果你向 seansheaton@gmail.com 发送邮件，Jocelyn 会收到你的邮箱地址、邮件内容及你选择附带的资料，仅用于回复咨询、解决问题和处理隐私请求。请勿发送密码或与问题无关的敏感信息。

邮件通过 Gmail 处理，邮件服务商会按其隐私政策处理相关数据。我们不会将联系信息用于广告，不出售个人信息；除提供邮件服务、依法履行义务等必要情形外，不向其他方披露。

4. 保存期限与删除方式

本地游戏记录会保留到你重置进度、清除应用数据或卸载应用。设置中的“重置游戏进度”会重建当前存档；应用可能仍保留上一次存档的本地备份。若要完整移除应用存档和本地备份，请在 Android 设置中清除本应用的存储数据，或卸载本应用。我们无法远程读取或恢复你的本地存档。

联系邮件仅在回复、解决相关问题及履行适用义务所需期间保存。你可以联系 Jocelyn，请求访问、更正或删除你通过邮件提供的信息；法律要求保留的信息除外。

5. 本网页与外部服务

本隐私政策网页托管于 GitHub Pages。访问网页时，GitHub 可能为提供和保护托管服务而处理 IP 地址及技术访问日志，具体见 GitHub 隐私声明。本网页不添加分析脚本、广告、追踪 Cookie 或联系表单。

点击邮箱链接会打开你选择的邮件应用，发送前由你确认；游戏存档不会自动附带发送。访问外部网页或使用邮件服务时，相应服务商的隐私政策适用。

6. 儿童隐私

当前离线游戏不要求玩家提供姓名、年龄或其他个人信息，也不主动收集儿童个人信息。若你认为儿童通过联系邮件向我们提供了个人信息，请联系 Jocelyn，我们会核查并处理删除请求。

7. 安全与政策更新

我们将数据处理限制在上述用途，本地存档由设备的应用私有存储保护。请妥善保护你的设备。若将来增加联网功能或改变数据处理方式，我们会更新本政策及生效日期，并在适用时于相关功能启用前提供说明和取得必要同意。
